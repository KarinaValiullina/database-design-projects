# 🗄 Проектирование и реализация баз данных

Добро пожаловать в мой репозиторий, посвященный проектированию и разработке реляционных баз данных. 

Здесь собраны проекты, выполненные в рамках обучения (Московский приборостроительный техникум) и самостоятельной практики. Каждый проект включает в себя этапы проектирования (создание ER-моделей), реализации структуры таблиц (DDL) и написания запросов/триггеров для автоматизации бизнес-логики (DML).

## 🛠 Использованные технологии и инструменты
*   **СУБД:** MySQL (MariaDB), SQLite.
*   **Инструменты проектирования:** ERWin Data Modeler, Draw.io, phpMyAdmin, Ramus.
*   **Языки программирования для интеграции:** Python (библиотека `sqlite3`), PHP (PDO).
*   **Ключевые концепции:** Нормализация, внешние ключи (Foreign Keys), связи 1:M и M:M, триггеры (Triggers), резервное копирование.

---

## 📂 Структура репозитория и описание проектов

Репозиторий разделен на папки по предметным областям. В каждой папке вы найдете `.sql` скрипты, диаграммы и описание.

### 1. 🛫 Информационная система «Аэропорт» (`/airport-system`)
Самая комплексная база данных в коллекции, включающая 12 взаимосвязанных таблиц.
*   **Суть:** Учет рейсов, пассажиров, сотрудников, продажа билетов и дополнительных услуг.
*   **Реализовано:** 
    *   Спроектирована логическая и физическая ER-модель.
    *   Реализованы связи «многие-ко-многим» через таблицы-связки (например, `Bilet_Ysluga`).
    *   Написаны SQL-запросы с использованием `JOIN`, `GROUP BY`, `ORDER BY`.
    *   Написано GUI-приложение на Python (Tkinter + SQLite) для работы с этой базой.

### 2. 🛒 Информационная система «Минимагазин» (`/minimarket-shop`)
База данных для автоматизации учета товаров и продаж.
*   **Суть:** Учет поставщиков, склада, продаж и истории изменения цен.
*   **Реализовано:**
    *   Использование каскадных правил (`ON DELETE CASCADE`, `ON UPDATE CASCADE`).
    *   **Триггеры для автоматизации:** 
        *   Триггер на поступление товара (автоматически обновляет остаток на складе).
        *   Триггер на изменение цены (сохраняет старую цену в архивную таблицу).
        *   Триггер на продажу (формирует чек и списывает товар со склада).

### 3. 🍳 База данных «Кулинария» (`/culinary-db`)
Учебный проект по созданию системы управления рецептами и ингредиентами.
*   **Суть:** Хранение ингредиентов, их калорийности и рецептов, в которых они используются.
*   **Реализовано:**
    *   Интеграция базы данных MySQL с веб-приложением на PHP.
    *   Защита от SQL-инъекций с помощью подготовленных выражений (Prepared Statements в PDO).
    *   Настройка внешних ключей для предотвращения удаления ингредиентов, которые уже используются в рецептах.

### 4. 🗂 Управление персоналом и аудит (`/staff-audit-triggers`)
Проект, демонстрирующий продвинутое использование триггеров для резервного копирования.
*   **Суть:** Учет сотрудников, должностей и отделов.
*   **Реализовано:**
    *   Созданы триггеры `BEFORE UPDATE` и `BEFORE DELETE`.
    *   При изменении или удалении записи о сотруднике, его старые данные автоматически сохраняются в таблицу-бэкап с указанием даты, времени и имени пользователя, совершившего действие. Это пример реализации простого аудита (Audit Log).

## 🚀 Как запустить проекты локально
1. Установите локальный сервер (например, OpenServer, XAMPP) или MySQL Workbench.
2. Создайте базу данных с нужным именем.
3. Импортируйте `.sql` файл из папки с соответствующим проектом через phpMyAdmin или консоль.
4. Изучите диаграммы и скриншоты в папке `docs` или `images` каждого проекта.
